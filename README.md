# mariaathena.com

Website for Maria Athena's fractional product management business. Static HTML/CSS/JS, deployed via GitHub Pages to www.mariaathena.com.

## Structure

- `index.html` — home
- `about.html` — bio
- `services.html` — engagement types
- `portfolio.html` — case studies
- `contact.html` — contact form / info
- `css/style.css` — styles
- `js/main.js` — nav toggle, small behaviors

## Local preview

No build step — open `index.html` directly in a browser, or serve the folder with any static file server.
